# TH-AI Passport Project Showcase

รวมโปรเจกต์ Open Source ที่พัฒนาด้วย **TH-AI Passport**  
รวบรวมซอร์สโค้ด ตัวอย่างการใช้งาน และลิงก์สำหรับทดลองใช้งานผ่าน GitHub Pages

## แนวคิดของโครงการ

โปรเจกต์นี้จัดทำขึ้นเพื่อรวบรวมผลงานที่สร้างด้วย TH-AI Passport ให้เข้าถึงได้ง่าย
ทุกคนสามารถศึกษา นำไปต่อยอด และร่วมพัฒนาได้ตามแนวทาง Open Source

## การใช้งานผ่าน GitHub Pages

เมื่อเปิดใช้ GitHub Pages สำหรับ Repository นี้แล้ว สามารถเข้าชมหน้าเว็บไซต์ได้ที่

```text
https://uhuboy.github.io/th-ai-passport-project-showcase/
```

## การนำไปใช้งาน

1. Fork Repository นี้ไปยังบัญชี GitHub ของคุณ
2. แก้ไขรายการโปรเจกต์ในไฟล์ `README.md` หรือหน้าเว็บไซต์ตามต้องการ
3. เปิดใช้งาน GitHub Pages จากเมนู **Settings > Pages**
4. เลือก Branch ที่ต้องการเผยแพร่ เช่น `main` และโฟลเดอร์ `/root`
5. แชร์ลิงก์ GitHub Pages เพื่อให้ผู้อื่นเข้าชมและทดลองใช้งาน
